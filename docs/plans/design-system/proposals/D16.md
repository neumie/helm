# D16 Hodnoty Remote mimo paletu

Rozhodnuto 2026-11-17: Send B · výplň `--text-0`, šipka `--pane` (§9 ruling 114); stíny A · dva stíny aplikace (§9 ruling 115); scrimy A · Remote bere `--scrim` (§9 ruling 116); offline stránka A · stupně Remote (§9 ruling 117). Nic nezůstává otevřené. Stories smazány.

**Otázka.** D7 A (§9 ruling 96) převedl Remote na plochy aplikace, ale ne jeho ostatní literály v `app/src/renderer/remote/remote.css` a na offline stránce (`app/assets/remote/remote-sw.js`). Každou skupinu buď převést na tokeny, nebo pojmenovat jako výjimku Remote. Lint baseline má 12 záznamů s D16 (`packages/helm-ui/lint-allowlist.ts`). Čtyři nezávislé otázky:

1. **Send button** — bílý kruh `#fff`, šipka `#0d0d0d`, hover `rgb(255 255 255 / 88%)`.
2. **Shadows** — menu doručení `0 16px 44px 48 %`, drawer navigace `20px 0 60px 48 %`, sheet More `0 20px 60px 55 %`, menu řádku `0 8px 24px 35 %` (přesná kopie `--shadow-1`).
3. **Scrims** — `.remote-sheet-dismiss` a `.remote-navigation-dismiss` `rgb(0 0 0 / 58%)` + blur 3px.
4. **Offline page** — text 16/1.6, h1 24 (prohlížečová váha 700), padding 48px 24px, vlastní zkrácený font stack. Barvy `:root` už generuje `npm run tokens:write`.

Storybook: `Proposals/D16 Remote values/…`. Každá varianta je skutečný produkční Remote (příběhy `Views / Helm Remote` Reading, Favorites a `Compositions / Menu and navigation / Finish item setup sheet`) v iframe 390×760, takže platí telefonní layout. CSS varianty je přidané na konec `<body>` rámu, za všechny styly aplikace; produkční soubory se nemění. Malé detaily jsou výřezy zvětšené 1.5–2×. Offline stránka je skutečný řetězec `OFFLINE` z `remote-sw.js` (čtený `?raw`, beze změny) v `srcdoc`.

Pozor na spec: open decision tvrdí, že `--scrim` je 55 %. V presetu Helm je **40 %** (`rgba(0,0,0,0.4)`), 55 % má jen High contrast.

## 1 · Send button

Kontrast proti kapsli = výplň proti `--chrome` 68 % přes `--pane` (jak ji kreslí `remote.css`).

| | šipka na výplni | výplň proti kapsli | High contrast |
| --- | --- | --- | --- |
| Current / A (bílá, výjimka) | 19.43:1 | 17.45:1 | beze změny |
| B · `--text-0` + `--pane` | 15.48:1 | 14.79:1 | `#0c0d0f` na `#ffffff` 19.44:1, proti kapsli 18.41:1 |
| C · `--accent-fill` + `--on-accent` | 4.51:1 | 3.86:1 | `#3473de`, šipka 4.51:1 |

- **Current** · literály, téma je nezmění.
- **A · výjimka Remote** · vypadá stejně, jen §3.23/§9 řekne „Send v Remote je bílý“ a lint ho pustí jen ve složce Remote.
- **B · `--text-0` fill (doporučuji)** · pořád bílý kruh, o odstín šedší (`#ececee`), šipka v barvě plochy, hover `color-mix(--text-0 88 %, transparent)`. Žádný nový token; High contrast dá čistou bílou.
- **C · primární tlačítko aplikace** · modrý jako každé primary. Konzistentní, ale na tmavé kapsli méně výrazný (3.86:1) a modrou už v Remote nesou odkazy.

## 2 · Shadows

Na tmavé ploše a za 58% scrimem s rozmazáním jsou rozdíly mezi variantami skoro neviditelné (ve screenshotech je musíte hledat); viditelné je to nejvíc u menu doručení.

- **Current** · čtyři literály.
- **A · dva stíny aplikace (doporučuji)** · menu doručení a menu řádku `--shadow-1`, sheet a drawer `--shadow-2` (§2.6: menu/popover → 1, sheet/modal → 2). Menu doručení má menší, měkčí stín; okraj mu drží `--hairline-strong`. Drawer vrhá stín dolů, ne do strany (na scrimu nepoznat). §2.6 zůstává „exactly two“.
- **B · `--shadow-3`** · nový token `0 20px 60px rgba(0,0,0,0.55)` (dnešní stín sheetu) pro menu doručení, sheet a drawer; menu řádku `--shadow-1`. Skoro jako Current; cena je třetí stín v §2.6 jen pro Remote.
- **C · výjimka Remote** · vypadá stejně; menu řádku dostane `--shadow-1` (přesná kopie), tři literály zůstanou pojmenované v §3.23.

## 3 · Scrims

Text `--text-0` pod scrimem: 58 % → `#636364`, 40 % → `#8e8e8f`; plocha `--pane`: 58 % → `#08090a`, 40 % → `#0c0d0e`.

- **Current** · Remote 58 % + blur, aplikace `--scrim` 40 %.
- **A · Remote bere `--scrim` (doporučuji)** · jeden scrim, téma ho řídí (Helm 40 %, High contrast 55 %). Za sheetem a drawerem zesvětlí; rozdíl je vidět, ale malý, protože blur 3px zůstává a pozadí pořád ustupuje. Aplikace beze změny.
- **B · výjimka Remote** · vypadá stejně, §3.23 pojmenuje silnější scrim telefonu.
- **C · `--scrim` na 58 % všude** · Remote beze změny, ale ztmaví se sheety aplikace (sidebar, Run Context, swipe zpět). Mění hodnotu tokenu → `PRESET_EARLIER_VALUES`; High contrast 55 % by pak byl světlejší než Helm.

## 4 · Offline page

- **Current** · text 16/1.6, h1 24/700, padding 48 24. Nadpis 24 px a odsazení 48 px nejsou na stupnici, 700 porušuje pravidlo vah 400/500/600.
- **A · stupně Remote (doporučuji)** · text 16 (beze změny), h1 21/600 (§9 ruling 101: Remote čte 16, nadpis 21), padding 32 24, `--font-ui` zapsaný generátorem do `:root` stránky, letter-spacing −0.01em. Nadpis menší a ne tučný, obsah o 16 px výš.
- **B · stupnice aplikace** · text 13/1.5, h1 17/600, padding 32 16. Na telefonu drobné písmo, menší než všechno ostatní v Remote.
- **C · výjimka offline stránky** · vypadá stejně, §3.23 řekne, že samostatný dokument bez `tokens.css` má vlastní typ a odsazení (h1 by zůstal 700).

## Doporučení

- **Send: B.** Vzhled zůstává (bílý kruh je signál Remote), ale hodnoty jdou z tokenů a High contrast funguje. A jen pojmenovává literál, C ztrácí výraznost (3.86:1 proti kapsli).
- **Shadows: A.** Dva stíny ze §2.6 pokryjí všechny čtyři plochy a rozdíl na tmavém pozadí skoro nejde vidět; třetí token ani výjimka si to nezaslouží.
- **Scrims: A.** Jeden scrim pro celý Helm, řízený tématem. Pokud se Jakubovi 40 % zdá na telefonu málo, lepší je C (zvednout token všude) než výjimka.
- **Offline page: A.** Stupně, které už Remote má (16/21), padding na stupnici, váha 600. Nic nového do spec.

Při implementaci: smazat 12 záznamů D16 v lint baseline, přepsat řádek §3.23 („The white Send button … are still Remote literals (D16)“) a §10 „enforced; D16“; offline stránka → generátor zapíše i `--font-ui` do `:root` v `remote-sw.js`.

## Mimo D16 (viděno při přípravě)

- Spec text D16 uvádí `--scrim` 55 %; v presetu Helm je 40 % (55 % je High contrast).
- `.remote-row-menu` používá `var(--radius-md, 6px)` s fallbackem a scrimy mají vlastní animace `160ms ease-out` / `180ms cubic-bezier(0.22, 1, 0.36, 1)` mimo motion tokeny (nejsou v D16).
- `node app/scripts/visual-diff.mjs capture` fotí po 250 ms, takže iframe rámy proposalů zachytí prázdné; ověřené screenshoty jsou s 7s čekáním.
